# Política de Privacidade - Base

Este arquivo é um ponto de partida para a versão comercial. Ajuste com apoio jurídico antes de publicar.

## Dados processados

Quando o usuário seleciona uma questão e usa a extensão, o texto selecionado é enviado diretamente para o provedor de IA configurado pelo usuário, como Gemini ou Groq.

## Chaves de API

A extensão pode armazenar localmente:

- chave pessoal do Gemini;
- chave pessoal da Groq.

Essas chaves ficam no armazenamento local do navegador e são usadas para chamadas diretas aos respectivos provedores.

## Retenção

A extensão não salva o conteúdo das questões em servidor próprio. O tratamento de dados pelos provedores Gemini/Groq depende das políticas desses serviços.

## Remoção de dados locais

O usuário pode limpar as chaves salvas no popup da extensão.
